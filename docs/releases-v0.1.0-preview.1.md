# Hasp v0.1.0-preview.1

把声音、蓝牙设备、外观和菜单栏整理放在一个面板里，这是 Hasp 的第一个公开预览版。

1. **常用控制**：切换声音输出、连接已配对的蓝牙设备，并查看设备提供的电量信息。
2. **自动外观**：支持浅色、深色、固定时间、自定义时段和日出日落切换。
3. **菜单栏整理**：收起不常用的状态项，需要时访问原生菜单，并修复同应用多进程状态项导致的崩溃。
4. **设置反馈**：修复开机启动开关成功后显示未同步，以及后来允许定位仍一直使用估算位置的问题。

需要 macOS 26.0 或更高版本，ZIP 同时包含 Apple Silicon 和 Intel 架构；解压后将完整的 `Hasp.app` 拖入“应用程序”。校验值见 `SHA256SUMS.txt`。

安装包已使用 Developer ID 签名，**尚未完成 Apple 公证**。macOS Gatekeeper 会拒绝常规打开；此包供愿意了解该限制的用户预览，请先核对下载来源和校验值。[Apple 关于打开 Mac 应用的说明](https://support.apple.com/102445)。也可以从源码自行构建。

本次使用 Xcode 26.6、Swift 6.3.3 构建，最低系统仍为 macOS 26.0。23 个无破坏性回归套件通过，覆盖切换取消与失败、耳机路由、折叠恢复、权限、面板生命周期和布局。当前实机环境为 macOS 26.6.2；macOS 27 折叠后端有自动化覆盖，尚待实机验收。真实设备切换、全部权限组合及完整人工界面验收仍待补充。

反馈问题请到 Issues，并先去除设备名等私人信息。
